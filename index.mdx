Doc Detective tests your documentation to make sure every command, example, and instruction still works, so your users don't get stuck.

<Card title="Get Started" href="/docs/get-started/installation" />

## If code is tested, docs should be too

Doc Detective performs your instructions step-by-step, just like your users would, and reports what works and what doesn't.

## How it works

1. <strong>Bring your docs.</strong> Whether in Markdown, AsciiDoc, DITA, or other formats, Doc Detective can read them.
2. <strong>Detect testable content.</strong> Doc Detective scans commands, code blocks, and examples users are expected to run.
3. <strong>Run the tests.</strong> Each instruction is executed in a real environment to confirm it works as documented.
4. <strong>Get actionable reports.</strong> See what passed, what failed, and where your docs need updates.

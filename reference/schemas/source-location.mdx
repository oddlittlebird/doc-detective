Source location where this step was detected in the original file. This is system-populated metadata and should not be set manually.

## Referenced In

- [Common](/reference/schemas/common)

## Fields

| Field | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| line | integer | Required. 1-indexed line number in the source file where the step was detected.<br /><br />Minimum: 1 | — |
| startIndex | integer | Required. 0-indexed character offset from the start of the source file where the step begins.<br /><br />Minimum: 0 | — |
| endIndex | integer | Required. 0-indexed character offset from the start of the source file where the step ends (exclusive).<br /><br />Minimum: 0 | — |

## Examples

```json
{
  "line": 42,
  "startIndex": 42,
  "endIndex": 42
}
```

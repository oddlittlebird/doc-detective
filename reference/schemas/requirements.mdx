## Referenced In

## Fields

| Field | Type | Description | Default |
| :--- | :--- | :--- | :--- |
| commands | array of string | Optional. Commands that must be resolvable on the PATH. | — |
| files | array of string | Optional. Files that must exist. Entries support `$VAR` and `$HOME` expansion. | — |
| env | array of string | Optional. Environment variables that must be set to a non-empty value. | — |

## Examples

```json
{
  "commands": [
    "node",
    "ffmpeg"
  ]
}
```

```json
{
  "commands": [
    "adb"
  ],
  "files": [
    "$HOME/.config/app.toml"
  ],
  "env": [
    "API_TOKEN"
  ]
}
```
